Selected Projects

Custom Painter Tool

Professional
  • Unity
  • C#
  • Unity Line Renderer
  • Custom Shaders

Description

A custom drawing system for a game in which the player draws their own avatar.

My contribution

An existing plugin did not provide the functionality and workflow the project needed, so I built the system from scratch on top of Unity Line Renderer tools: drawing with mouse and finger input, erasing, color changes, layered drawing, and combining the drawing layers into a final image.

Technical challenge

Layer compositing, erasing and blending could not be solved at the component level alone. I wrote custom shaders for compositing the drawing layers and for handling the erase functionality and blending correctly.

2D GPU Instancing System

Professional
  • Unity
  • C#
  • GPU Instancing
  • Performance Optimization

Description

A grid-based game with more than 1,000 cells, built from scratch following the visual design provided by an artist.

My contribution

I built the game from scratch against the provided visual design, then designed and implemented a GPU instancing system for the 2D environment.

Technical challenge

The animated map initially ran at approximately 20–40 FPS and suffered from significant performance problems, including visible stuttering and freezing.

Result

After the GPU instancing implementation, performance surpassed 100 FPS on the tested setup and the visible stuttering and freezing were eliminated.
